# AirLoop

An English product showcase for a graduate Science & Technology English group project.

AirLoop is a fictional smart-home air-management concept: a discreet wall sensor and a quiet ventilation module that sense, learn, and act. Product renders and technical specifications are illustrative design concepts.

## Website

This repository contains a standalone static website. Open `index.html` locally, or publish the repository root with GitHub Pages from the `main` branch.

- `index.html` — English product copy and page structure
- `styles.css` — responsive styling
- `app.js` — accessible feature tabs and prompt copying
- `assets/` — two illustrative product renders
- `.nojekyll` — serve the static files without Jekyll processing

All assets use relative paths to support a GitHub Pages project URL. No API keys, backend, or external libraries are required.
